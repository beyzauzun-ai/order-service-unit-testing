# 🧪 Order Service - Unit Testing with AI

This project demonstrates how to generate and validate unit tests for a Python-based order service using AI tools.

## 🚀 Project Overview

The system simulates an order checkout process including:

- Cart validation  
- Stock availability check  
- Price calculation  
- Payment processing  
- Inventory update  

## 🧠 Key Features

- ✅ Unit tests written using **pytest**
- ✅ Mocking external services with **unittest.mock**
- ✅ AI-assisted test generation and validation
- ✅ Covers multiple real-world scenarios

## 🔍 Test Scenarios

The following cases are tested:

- Empty cart validation  
- Insufficient stock handling  
- Successful checkout flow  
- Payment failure handling  
- Inventory update after successful payment  

## 🛠️ Technologies Used

- Python  
- pytest  
- unittest.mock  
- AI (Gemini / Antigravity)

## ▶️ How to Run Tests

```bash
pip install pytest
pytest
```
